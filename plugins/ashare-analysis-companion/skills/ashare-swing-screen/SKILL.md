先检查当前会话实际可调用的工具与 schema。只有 `get_swing_screen` 已可见且本次返回成功，才称为使用波段筛选工具；服务已发布、工具列表里写了名字、技能已更新均不代表此处可调用。新工具不可见时按下文降级，不构造不存在的工具调用。先读 [筛选契约与公式](references/screen-contract.md)，参数与结果仍以当前真实 schema 为准。

筛选行情使用保留的公开来源，目录范围按下文无凭据官方主板契约取得。公开源码不提供云端私人自选、桥接、账号竞价或采集控制。私人名单只能在授权本地环境处理；其他金融账户的名单不能代替用户要求的范围。

## 执行一次筛选

1. 核对证券身份和范围。明确代码可直接使用；中文名称先用实际支持名称解析的 `get_quotes` 核对唯一精确名称、代码及市场，再把确认的代码交给筛选工具。名称歧义、无精确匹配、报价名称不符时停止该项，不选首个候选。用户明确要求一个完整目录范围时，按下文固定主板目录契约形成名单，不缩成自选股、热门股或首批样本。名单/目录均不可取得时说明缺口，再请用户说明范围、提供无私有内容的公开代码名单或选择本地路径，不索取私人名单，不编造股票池。
2. 默认采用已公开的固定阈值。云端不接受 `thresholds`；用户要求调整时只在已核实支持的授权本地环境修改并展示实际值；不要根据新华传媒等已知赢家的后续涨幅反向优化阈值。每项判断需能回溯到实际数据和规则。
3. 云端明确使用 `universe=explicit`，每次 1–20 个公开代码和固定预设。大公开目录名单分批时保留冻结名单、批次和各自时点，不称原子快照；用户要求整个目录范围时执行下文全部批次，不能只运行首批。私人自选和定制阈值不传云端。
4. 分别保留 `match`、`not_match`、`insufficient_data`。数据不足或单股错误不能当不符合条件；空名单、整批错误不能解释为市场没有机会。只把 `phase=emerging` 说成“符合趋势初起规则”，把 `continuation` 说成“符合趋势延续规则”，不是已证实的市场阶段或买入信号。
5. 按返回的去重后输入顺序或透明分组呈现；数量以实际去重和完整批次结果为准。不自造综合评分、胜率、预期收益或“最值得买”排名。过热风险不会自动删除匹配项：单独解释 `risk_flags`，不能把未提示过热说成低风险。

## 时间、数据与证据

- 使用腾讯前复权日线这一条经验证路径，最多请求 200 根，至少需要最近 65 根有效且完整的日线及其会话连续性证据。不能用未复权、其他来源、日线缓存或跨源拼接补足后再声称筛选成功；这不禁止下文单独标识的公共目录缓存
- 筛选目标是冻结请求开始时刻最新已完成预定会话。仅当Asia/Shanghai严格晚于15:30:03发起的新请求取得目标日有效行并通过腾讯qfq/65会话质量检查时，当天日线才可入样；恰好该时刻及之前不能入样，跨线不升级旧缓存。说明实际截止日、eligibility_version=verified-postclose-v2及source_finality=unknown，不称盘中实时或源最终认证
- 检查 `freshness`、样本首末日期、来源时间、接收时间、实际数量及警告。源陈旧、日历覆盖未知、缺交易日、无效数据或样本不足都应保留数据不足结论；节假日较旧的日期不一定是过时，按工具确认的预期交易日比较
- `source_timestamp` 可能是 K 线日期标签；`fetched_at` 是接收时间，不把两者冒充交易所实时成交时间。前复权价格用于同口径历史比较，不直接作为当前未复权下单价；成交量是未作价格复权的股数，除权或股本变化可能使量比失真
- 仅有价格和成交量形态不能证明“主力进入”、资金净流入、确定的吸筹或未来拉升。财务质量、行业归属及同口径历史强弱、ST/退市、停复牌和实际可成交状态尚未核实时，分别说未核实，不把筛选名单称为已经排除这些风险
- 没有覆盖完整上市/退市证券且带历史成员日期的股票池、当时可得数据和执行成本证据，就没有全市场发现或无偏历史回测依据。对某股现有历史条形做规则回放只称“事后规则诊断”；披露事后选样、现时复权/修订、幸存者与前视风险，不报告为经过验证的策略收益或胜率

## 中文输出

先给一句最有用的结论，例如“这 8 只里有 2 只符合固定波段规则，另 1 只因历史缺口不能判断”。随后简述：

- 实际股票池、已处理/待处理范围、截至的交易日、前复权口径与来源
- 匹配股票的阶段、触发的具体规则和指标，仍未满足的条件、过热与其他相关风险
- 未匹配与数据不足分开，给最关键的原因；没有候选就直说，不为凑名单放宽规则
- 下一步可观察的延续或失效条件，所有价位和数字来自本次数据或明确计算

不把筛选匹配等同交易建议或预测，简要提醒假突破、行情反转与成交限制。需要讨论实际买卖时，再核实适用交易规则、费用、滑点和可卖数量；规则未核实不作成交或净收益假设。本技能不下单、不开户、不转账、不创建自动交易、通知、持续监控或新的长期授权。一次筛选和“别错过”都不等于已建立提醒。

### 冻结名单、日期与覆盖账本

固定本次 `manifest_hash`、`universe_version/manifest_version`、公共来源版本、各所独立日期/原始接收时间、去重证券身份、预期已完成交易日、规则版本与默认阈值。目录hash绑定排序后的完整分类公开身份、分类规则和各source_id的来源依据，原始取数时刻、行/来源顺序及筛选截止日不改变hash，来源展示日期可改变hash。`source_timestamp=null`表示没有经认证的共同生效时间；`snapshot_timestamp`仅是本地组合接收标识，不是成员生效时刻。相同hash不证明同一筛选代次或原子行情时点；不伪称掌握被省略的完整分类行明细。

必须对账两个互斥等式：

- `provider_rows = eligible_mainboard_non_st + excluded_st_name + excluded_other_boards + unclassified + unsupported`
- `eligible_mainboard_non_st = match + not_match + insufficient_data + failed_without_result + pending`

`unsupported`先于板块/名称归类；支持格式与实际数据可得不同。未分类、不支持、失败、待处理和unknown状态单列。新公共目录须三响应全部有效并对账；一所失败或沪市超固定2000首屏上限时不可拼成部分池或伪造零股票。当前两所目录计数对账不证明历史成员、全量原子性或可成交，`complete_exchange_universe=false`、`ordering_and_atomicity=not_atomic`及上市/退市/停复牌/ST/可成交unknown继续保留。

先读cache来源：同上海日期的isolate内6小时公开缓存不是后台刷新或全局持久缓存；失败有60秒冷却，无自动重试。只可返回同上海接收日、至多24小时的已验证旧公共快照，须标明 `stale_fallback`、刷新失败/非新鲜并保留原始日期/时刻/hash。跨日/超龄/无旧快照时 `public_source_unavailable`、coverage=null，不能以空items称零候选。命中/共享等待不等于本次再次取源；不把 `served_at` 当原始取数或源生效时刻。

### 逐批处理与失败

对全部已冻结的入围代码，沿用 `get_swing_screen` 显式模式、顺序批次每批最多20只、腾讯前复权来源与65根已完成日线门槛；既有初起/延续公式、独立过热标记不变。每批核对同一规则/defaults/cutoff、精确代码/无重复/无缺项、结果形状、样本/来源与有限指标、checks/phase/status的一致性。来源不合规或日期/规则变化不拼接成旧结果。

- 有效 `insufficient_data`（包括来源超时且其预期日为null的合法结果）仍计入数据不足，不计为请求失败或不匹配
- 整批调用失败，或缺项/重复/池外/形状无效等没有可信逐项结果时计 `failed_without_result`，保留失败与未执行；不能用 summary 默认零造出“零候选”
- 新页面流程无自动重试、源替换、调参或小范围自动探测。Continue 仅处理 `pending`，用户触发 Retry Failed 仅重试 `failed_without_result`；有效数据不足不会被该按钮重新运行。认证、访问拒绝、请求错误或明确限流时暂停，不自行继续发请求
- 规则/defaults/cutoff变化锁住继续/失败重试，须用户明确开始新代次，不把新旧名单或日期拼接。无效批次不得改变已有有效结果；重试终态替换原失败记录，不重复计数

只有 `failed_without_result=0` 且 `pending=0` 才说“本次冻结来源名单已全部处理”；数据不足仍必须单列，不能称全部已判定或完整全市场筛选。有失败但pending为零时至多说“已尝试处理”，同时报尚无结果的数量。允许零匹配，不凑评分/收益/胜率或按已知赢家优化。

### 页面内任务不是后台任务

说明当前公开页面实现的能力：用户明确启动后，页面按公共缓存契约取得本次目录并在页面内逐批执行，命中缓存不等于此次重新读取官方站点；暂停只阻止当前请求结束后的新批次。关闭页面不会继续执行或保存进度账本；隐藏页面暂停新批次，返回不会自动恢复。切换行情图表/集合竞价/波段选股/数据设置四个工作视图会保留并继续已经启动的筛选，但不新建筛选或控制后台采集。重新运行经确认后替换本页结果与进度，不拼接代次。

页面的过热展示过滤只突出带标记的匹配，不取消匹配，也不把无标记称低风险。一次页面筛选不是提醒、后台监控、云采集或交易授权。一次公共目录成功不是日线筛选成功或盈利验证；实际界面、当前来源和本地数据接入仍需分别验证；离线 DOM/fixture 测试不能代替。

## 筛选之后的策略验证

用户询问回测、胜率、收益、调参优劣或仓位风险时，读取 [策略验证与风险审查](../ashare-strategy-validation/SKILL.md)。现有筛选契约、来源、阈值和状态语义保持不变；新增研究流程不提供历史截止日、回测、评分或仓位接口。教材理论、合成验算和现时数据的事后诊断不能证明A股样本外盈利。允许零候选和现金等待，不为凑名单、追回亏损或已知赢家倒推而自行放宽条件；原有过热阈值不是最大可亏损比例。
