# A 股行情与条件分析

## 取数与问题范围

对当前价格、涨跌、成交量、K 线和技术信号先取数，不用记忆中的报价或假数据。本插件仅提供分析技能，没有行情服务器或交易工具。使用已连接的 A 股行情插件实际提供的 `get_quotes` 与 `get_bars`；先查看当前工具参数与结果结构，按其支持的股票代码、市场、周期和范围调用。插件未连接或工具不可用时明确说明，不能假装成功调用。

普通报价查询只取所需行情并直接回答。用户要求分析时，再按其时间跨度取足够的 K 线。支持工具覆盖范围内的 A 股，不限于示例股票。名称或代码存在歧义时先核对，不默认为同名证券。只有投资期限、风险承受或持仓信息会实质改变所问结论时才追问；不编造用户的持仓、成本、可用资金或交易经验。

## 当前版本与未完成范围

本公开源码的当前能力以实际 schema、description 和返回为准；保留工具名字不等于保留原私有服务的全部参数或功能。get_stock_directory、get_auction_snapshot、get_auction_series、get_archive 四个云端兼容名字均 unsupported，云端只支持公开显式代码的固定规则筛选；被动诊断不能恢复旧能力。先读 [盘后完成与留存边界](references/data-coverage.md#盘后完成与留存边界)。

公开 Worker 已物理移除行情数据库读写、云端持久回退和本地留存 opt-in；不读取既有 D1 快照或归档，get_archive 在云端返回 unsupported。默认 db/schema.ts 为空导出，云端 SQL 不建表、不迁移、不删表；云构建没有 SQL writer、行情 schema 或 portable 存储依赖。官方公共目录只保留有界 isolate 内存缓存。

手工观察、归档、快照回退与私人自选存储只存在于仓库的 portable/local-market.mjs、portable/local-watchlist.mjs、portable/local-observation-store.mjs，须由 portable/sqlite.mjs 的 Node DatabaseSync 工厂签发不可变、仍打开的本地能力。通用 D1、任意 env、客户端 JSON 标记和已关闭实例均被拒绝。显式 127.0.0.1 Node 宿主支持获授权的手工查询与本地留存；此次源码交付未启动实际本地服务。许可存疑行情只在获授权本地保存，不进 Git 或云端长期归档；源码不带真实档案。私人密钥、名单、条件和结果不提交云工具。独立的 OHLCV 更新内核仍未接真实 loader、更新路由或连续/盘后调度；0.1.4 开发条件页面只提供 10 条虚构池记录的合成演示。离线构建和测试不证明目录可访问、真实更新完成或策略盈利。

腾讯/新浪报价与 K 线、东方财富延迟盘前观察点和公开背景工具分别以本次有效返回为证。保留来源、时间及各自失败；不能把一个源成功说成全部数据齐备。公开源码没有可选云端桥接或账号竞价采集能力。私人自选只属于授权本地路径。

- unavailable、unsupported、缺失与成功空结果分开；不把被移除能力当成等待配置的服务
- HTTP 401/403 只证明访问被拒；配额、限流、凭据原因须有独立明确证据，不自行推断
- get_diagnostics 是被动状态说明，不发来源请求；实例内历史观察不证明实时源健康、后台采集或长期可靠性
- 用户要求停止某来源查询时遵守该范围，不借其他工具、诊断或源替换继续探测

### 股票名称与身份核对

遵循当前 `get_quotes` schema：仅在工具明确支持名称查询时传中文名称，不向只收代码的接口硬塞名称。数据层若返回唯一精确匹配的证券代码、市场和名称，再用该已确认代码请求其他接口；名称不唯一、相似匹配、别名或结果名称不符时先列候选并请用户确认，不按熟悉程度、热度、排序或第一个结果选股。不自行将“唯一搜索结果”升级为“精确身份已核实”。中文名称能力未进入当前工具目录或未得到有效结果时，如实说明并请用户提供证券代码，不能声称本技能已新增行情接口。

## 证据与时效

- 展示行情来源、市场/代码、报价或 K 线的源时间、接收时间及其时区；不把接收时间当成成交时间。区分当前报价、最近交易时点数据、延迟数据、盘后数据和历史数据
- 按工具给出的时效与交易状态判断是否可用于当前问题。缺少源时间或新鲜度证据时说“无法确认实时性”；交易时段、休市或停牌无法确认时，不自行定性
- 价格说明币种；量、额和涨跌幅使用结果中的明确单位。缺值与错误不能当作零。发现单位缺失、冲突或明显异常时暂缓依赖该字段的结论
- K 线需标明周期、时间范围及复权口径。不同周期、口径或来源的数据不能无说明地拼接或比较
- 抓取、字段解析、单位转换、源降级由数据层完成。使用结果里的来源与质量提示，不在回答中猜测单位，也不临时绕开数据层编写抓取逻辑。数据不足时说明缺了什么及哪些判断因此不能做

## 分析与表达

用已完成 K 线计算或确认技术信号；当前未完成 K 线只能描述为盘中变化，不能声称收盘确认。使用均线、突破、支撑或量能对比时，说明计算窗口、基准与足够的数据依据。历史样本不足就收窄结论，不凭一张报价快照推导走势结构、资金流入、主力意图或胜率。

面向中文入门者，先用一句话回答当前能判断什么，再给少量关键证据；术语首次出现时顺带解释。把已观察到的事实与有条件的推测分开。用户问“能不能买/卖”时，给可观察的条件和失效条件，例如“先等这一周期收盘确认……；若随后跌回……，该判断失效”，并说明这些条件仍可能失败。具体价格和阈值必须来自实际数据或清楚标注的计算/假设，不能为凑出建议而编数字。没有优势或证据不足时可以直说“先等”“暂时不能确认”。不保证收益，不把模型判断包装成确定预测。

交易相关结论要考虑所涉证券适用的 T+1、停牌/涨跌停导致无法成交、滑点及交易费用；适用规则或费率不确定时核实当前官方规则，不套用统一费率或把股票规则扩展到所有产品。收益估算需说明成本假设，缺少费用时仅称毛收益。

### 仅在用户明确询问时讲解“做 T”

先说明“做 T”在本回答中是利用可卖底仓与后续回补尝试管理日内价差的条件教学，不是保证获利的方法。分清先卖后买与先买后卖的流程、未回补/追高以及下跌风险；先核实所涉证券适用的交易规则和可卖数量。不能暗示今日新买入的普通 A 股可当日卖出，不能凭账户总持仓推定全部可卖。没有持仓、可卖底仓、成本或费用资料时，不代填也不算用户的股数、净收益或仓位比例；只需一般教学时不强行索取这些资料。

只用本次分时、同口径成交量和已完成周期的真实证据讲可观察条件，分别给触发、等待与失效情形。价位须来自可回溯的数据/计算；若只是演示，所有数字明显标为“假设示例”，不得混入当次真实行情结论。若支持数据不足，先指出不能确定具体做 T 价位，仍可解释流程与失败情形。量价或盘口只支持条件判断，不支持“主力一定拉升”“必然回补”“稳赚差价”。交易费用和滑点未核实时不把毛价差称为净利润，也不假定一定成交。不下单、不创建盯盘或交易授权。

此技能只支持查询与用户要求的分析，不执行交易、不代为开户或转账，不创建自动交易、持续监控或新的长期授权。一次查询不代表持续盯盘；用户另行要求监控时按实际支持的流程和权限处理。

## 完整分析请求：先核对覆盖，再下结论

用户要求“完整数据”或分析“主力意图”时，不把多个成功接口等同于完整行情。先报告本次数据覆盖：报价/成交价、分时价格、分时成交量、集合竞价、MACD、日/周/月 K 线与对应成交量，逐项标记“可用”“部分可用”“缺失”并说明时间范围；可用也必须以本次成功返回为证。缺失项不能用推测补全。普通单项查询无需跑所有接口。

读取 [数据覆盖与指标口径](references/data-coverage.md)，按实际发现的工具 schema 请求数据。其工具名是已实现候选，只有当前工具可见且调用成功才能使用；能力尚未部署、连接未刷新、接口报错或结果为空时明确说不可用，不声称已取到。不得自行创建数据接口、绕过数据层抓取或生成占位行情。

### 分时、成交价与分时量

- 分钟价格点不是逐笔成交明细，报价快照也不能证明其间每笔成交价。需要逐笔数据而工具不提供时，直接说明缺失
- 分时量若是累计成交量差分，首点未知不能当成首分钟成交量；两点相隔多分钟、午休或缺口时，不当作一分钟放量。检查 `interval_minutes`，跨缺口只能描述整段量；不虚构缺失分钟或插值成实际成交
- 不能把当日未完成量直接与完整日/周/月量相比宣称缩量；同时间对比需要往日相同时段数据，否则只描述已累计多少。量比、换手率须有相应基准和流通股本，不凭总量反推
- 量、额都存在且口径一致时才用额/量计算均价；累计量经取整的均价是近似值。金额缺失时不能拿收盘价乘成交量冒充成交额

### 日、周、月与 MACD

- 日、周、月价格和成交量使用各自周期K线，分别核对complete、calendar_completion、completion_basis、source_finality、样本量、复权和来源。本公开服务在Asia/Shanghai严格晚于15:30:03发起的新请求，目标日有效日线可按已核2026日历推定完成；恰好该时刻及之前仍未完成，不能由时钟跨线升级旧盘中缓存。source_finality始终unknown，日历覆盖外或跨覆盖边界的旧complete=true只作已过自然周期展示，不认证完整历史。当前周/月形成中必须单列，不能混作已完成信号
- 先看大周期趋势，再看短周期是否一致；不同周期矛盾时明确呈现，不强行给统一方向。不能只看一根 K 线认定趋势或稳定支撑
- MACD说明周期、12/26/9参数、柱值倍数与预热不足；保留基础K线同一冻结completion_cutoff及逐点完成证据，不用响应结束时刻重判。交叉至少需要相邻两个同口径有效已完成点；未完成点交叉只能描述当前暂态。历史不足、日历证据未知或初始化敏感时减弱结论或不判信号
- 背离需价格与指标对应的已确认转折和足够样本；只出现一涨一跌不是背离。MACD 是历史价格的变换，不是资金流或未来收益证明
- 复权序列用于同口径历史比较；不可直接把复权支撑价作为当前未复权交易价。负数/明显异常复权价格、不同复权序列混用时暂停相关价格结论并核对

### 归档、大盘与行业背景

- 云端 `get_archive` 为 unsupported / PUBLIC_PROFILE_LOCAL_REQUIRED，不读取数据库或来源，不能描述为已读到归档。只有已核实授权、具有工厂签发的开放 NodeSQLite 能力的 127.0.0.1 本地入口可读取已完成观察记录；没有上游补抓或后台采集。该本地结果按股票、来源、周期、复权口径隔离；`has_more=false` 只代表本地存档分页结束。顶层 `fetched_at` 是本次读档时间，原收取时间看 `provenance.first_fetched_at` / `last_fetched_at`；存档不能称实时、完整历史或全部旧修订，源码不带真实数据库
- `get_market_context` 的六个宽基指数以“点”计，不是人民币报价；各指数分别核对时间与错误。行业榜单按 `industry_context.source`、条目时效和分类口径解读，不依赖顶层来源摘要。东方财富延迟行业榜与新浪行业平均涨跌幅回退不可混合；新浪平均涨跌幅不能代替个股涨跌幅，也不能当东方财富行业指数
- 行业源缺少已验证更新时间/所属会话，`freshness.status=unknown` 时只能说“本次取得的来源榜单，实时性无法确认”。接收时间或日期形状字段不能证明实时强弱；新浪本次49类不是固定或全市场覆盖保证。上下榜分类可能重叠，不能相加推导全市场涨跌家数、资金净流，也不能据此确认个股所属行业或机构意图
- `get_stock_context({symbol})` 可用且调用成功时，按新浪个股页明确关联的 `membership.code/name` 与同源 `sector_context` 解读。必须保留来源分类名称、证据链接及未知生效日期；不能替换为申万、证监会或东方财富行业。只在精确代码和名称匹配时关联，部分失败分别披露，不按公司名猜归属。`rank_descending` 只是在同一49类有效响应中的竞争排序，并列同名次；数量变化时排名为null，不宣称全市场覆盖。板块更新时间仍未知，不计算个股减板块涨跌幅或断言实时跑赢。`history.available=false` 时不拿其他分类/个股历史代替；停复牌状态仍未知。新工具未进入当前会话目录时明确不可调用，不把服务列出工具名当成本次取数成功
- 涨跌停字段仅在同一选中腾讯沪深报价快照内、`provider_fields_verified=true` 时说明来源上限/下限和价格关系。`verified=false` 仍表示交易所有效规则与停牌未核实；到达限价不等于封死或无法成交。不按代码自行套10%/20%/30%，不跨源拼接限价；北交所及新浪回退限价、所有停复牌状态未知时明确说未知

### 集合竞价与“主力意图”

- `get_auction` 给出东方财富延迟盘前分钟观察点，不是实时或完整集合竞价专用行情。旧账号竞价快照和过程工具在此公开源码中 unsupported；不能与东方财富数据混拼或用其补全。可能缺少最终撮合价、虚拟匹配量、未匹配买卖量、撤单、逐笔订单及 Level-2；逐项按返回能力和警告披露
- `auction_quality` 分别统计09:15–09:19、09:20–09:24及09:25–09:30的来源标签；缺口、非当日、未来标签和不一致OHLC需按错误/警告处理。零缺口或16个观察点也不能认证完整竞价、撤单过程或最终撮合，不能补造被拒绝的观察值
- 09:30 开盘价或源标注 09:26 的观察值不能冒称经验证的 09:25 最终撮合价；零观察成交量不代表无人申报或未匹配量为零。没有撤单字段就不能分析撤单率或断言诱多撤单
- “主力吸筹/洗盘/拉升/出货”只能作为带条件的解释假设，不能当作事实、确定意图或已识别交易者。相同量价形态可能来自市场联动、被动调仓、消息、流动性或短期交易，至少给出一个合理替代解释
- 用“观察到……；这与……假设相容，但也可能……；只有后续出现……才增强该解释，若……则削弱”表达。验证条件必须来自可观察数据，不能编造价位、净流入、机构仓位或胜率
- 即使盘口买量大于卖量，也不能等同净流入或机构买入；没有逐单身份与完整交易证据，不能证明买卖方是谁

### 被移除的账号竞价能力

get_auction_snapshot 与 get_auction_series 在此公开源码中仅保留旧名字/schema，返回 available=false、data_status=unsupported、PUBLIC_PROFILE_LOCAL_REQUIRED；零数据库、凭据或来源读取。它们不返回实时快照、账号留存或过程曲线。get_diagnostics 不作专有来源探测，也不能替代这两个工具。

公开数据设置没有密钥输入、桥接或采集控制；被移除能力没有配置或恢复流程。不要指导用户保存/测试密钥以启用它们，也不要读取凭据文件、环境变量或密钥表。确需另一环境的能力，先核实该环境真实契约、授权和本地边界，不能凭本源码声明它已经可用。

### 诊断与稳定性

get_diagnostics 只提供公开服务版本/schema、日历/市场状态和当前实例的公开请求观察，不读数据库、密钥或来源。成功只证明该次元数据读取；不能证明来源恢复、跨日稳定、低延迟 SLA 或后台监控。源码评审与版本核对使用离线证据，不为验收触发真实行情请求。工具可见、本次调用成功和长期可靠仍是分别需要证据的状态。

## 建议的中文回答结构

先用一两句回答用户最关心的问题，并给最影响结论的数据缺口。普通分析先挑两三条最有用的事实，避免堆全部指标或重复风险模板；完整分析再列覆盖。数字、单位和时间紧邻证据，结论强弱与证据相称。按请求深度选择以下内容，而非每次机械填满：
1. 数据覆盖与时效：来源、时间、完整/部分/缺失项
2. 事实证据：分时价量、日/周/月结构、MACD与竞价可观察项，所有数字可回溯工具结果
3. 条件解释：支持与反例、替代解释、后续验证/失效条件
4. 限制与风险：未完成周期、缺失竞价/逐笔/L2、历史不足等与本题实际相关的限制

如用户只问一个报价，直接回答报价与来源时效即可，避免套入长模板。本技能不承诺所有数据完整，也不把“未发现证据”说成“证明没有”。


### 公开竞价时窗与观察覆盖

- 东方财富 freshness.status 为 historical_auction_observations 时说当日早盘历史记录；prior_session_observations 为往日记录；delayed_recent_observation 或 delayed_observation_lagging 仍是延迟观察，不能称实时竞价。缓存保留原时间与 underlying_status，不把历史窗口当当前快照
- 源点数、分钟标签和缺口只描述该来源的观察窗口，不证明交易所全量、撤单或最终撮合。缺少观察不等于零成交；full_auction_feed=false 不可改为完整竞价
- 公共查询不新增云端竞价留存；旧账号快照、过程读取和采集控制均被移除。合成测试或已有文件不能证明后台持续采集

## 策略可靠性与风险审查

仅当用户进一步询问历史绩效、回测、参数优劣、仓位或组合损失时，读取 [策略验证与风险审查](../ashare-strategy-validation/SKILL.md)；普通报价和量价解释不扩成全套研究。先区分当前观察、研究假设与真实验证证据，不把教材或合成验算说成A股策略有效。损失承受、现金需求和可卖数量未知时不代填仓位或止损百分比；可以等待、没有交易，不因漏选或回本动机自行扩大风险。历史回撤与止损条件均不是未来亏损上限。
