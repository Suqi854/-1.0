## 公开源码分发能力边界

此技能源码变体为 1.9.29-public.2，配套 1.27.0-public.2 / public-no-credentials-v2。它与运行中的私有服务及正式安装的 1.9.29 技能能力不同。公开云端的 14 个 MCP 名字中，get_stock_directory、get_auction_snapshot、get_auction_series、get_archive 是四个 unsupported 兼容占位；返回 PUBLIC_PROFILE_LOCAL_REQUIRED 和 local_required=true，不读取环境、数据库、凭据或来源，也不写入数据库。get_diagnostics 仅返回被动元数据与当前实例请求观察，不作上游探测。公开代码不含凭据设置、Access 桥或采集器执行流程；不能通过配置密钥启用被移除功能。

云端筛选只接受公开显式代码和固定 swing-daily-v1；私人名单、阈值、条件及结果只在授权本地执行。无密钥 OHLCV 内核已经准备，但真实 loader、连续更新与盘后调度尚未接入。条件模块 0.1.4（开发候选） 只有 10 条虚构池记录及合成行情，不是实际行业龙头池。详见 [公开技能能力声明](../../PUBLIC-PROFILE.md)。

# A 股策略验证与风险审查

目标是发现会让研究结论失真的条件，优先约束不可承受的损失。允许没有候选、没有交易和现金等待；不以追回亏损或怕错过为理由自行扩大风险。不能承诺保本、避免一切回撤或一定找到主升浪。

本技能只增加研究与解释流程，没有新增行情、历史回测、组合下单或监控接口。报价与量价事实仍用 [行情分析](../ashare-analysis/SKILL.md)；一次固定筛选仍用 [波段筛选](../ashare-swing-screen/SKILL.md)。不要为一个普通查询启动全市场扫描或强制完整研究。

## 当前版本与未完成范围

本公开源码的当前能力以实际 schema、description 和返回为准；保留工具名字不等于保留原私有服务的全部参数或功能。get_stock_directory、get_auction_snapshot、get_auction_series、get_archive 四个云端兼容名字均 unsupported，云端只支持公开显式代码的固定规则筛选；被动诊断不能恢复旧能力。先读 [盘后完成与留存边界](../ashare-analysis/references/data-coverage.md#盘后完成与留存边界)。

公开 Worker 已物理移除行情数据库读写、云端持久回退和本地留存 opt-in；不读取既有 D1 快照或归档，get_archive 在云端返回 unsupported。默认 db/schema.ts 为空导出，云端 SQL 不建表、不迁移、不删表；云构建没有 SQL writer、行情 schema 或 portable 存储依赖。官方公共目录只保留有界 isolate 内存缓存。

手工观察、归档、快照回退与私人自选存储只存在于仓库的 portable/local-market.mjs、portable/local-watchlist.mjs、portable/local-observation-store.mjs，须由 portable/sqlite.mjs 的 Node DatabaseSync 工厂签发不可变、仍打开的本地能力。通用 D1、任意 env、客户端 JSON 标记和已关闭实例均被拒绝。显式 127.0.0.1 Node 宿主支持获授权的手工查询与本地留存；此次源码交付未启动实际本地服务。许可存疑行情只在获授权本地保存，不进 Git 或云端长期归档；源码不带真实档案。私人密钥、名单、条件和结果不提交云工具。独立的 OHLCV 更新内核仍未接真实 loader、更新路由或连续/盘后调度；0.1.4 开发条件页面只提供 10 条虚构池记录的合成演示。离线构建和测试不证明目录可访问、真实更新完成或策略盈利。

## 私有策略仅在本地验证

公开行情与插件已公开的通用固定规则可以用云端；用户个人密钥、自定义量化策略代码/公式/阈值、私人自选/持仓与其他私有资料必须留在本地，不上传至Site、云工具、云文件、自动化或插件release。通用固定规则不是用户私有策略；不能据公开行情的授权推导私有内容也获准上云。

研究私人策略时先核实授权本地执行路径，仅在本地读取、运行和保存输入/结果；能力未接入时说明阻塞，仍可解释公开方法。公开源码没有密钥设置或凭据探测，get_stock_directory、get_auction_snapshot、get_auction_series、get_archive 四个云端兼容工具返回 unsupported；不能通过配置或诊断恢复。get_mainboard_universe 是固定 SSE/SZSE 无凭据公共分支，云端 get_swing_screen 只支持公开显式代码与固定预设；这不授权私人资料、名单或阈值上云。

## 先确定本次能回答什么

区分教材理论、独立合成验算、真实A股样本内、按时间划分的样本外、前瞻纸面记录与真实成交结果。只报告已经取得的证据；来源不是A股、只是数值测试或事后选样时明确标注。读完书、求解器收敛、代码测试通过均不能升级为盈利验证。

- 审查回测、历史收益口径、定投方案比较、参数或选股优势：读取 [验证流程](references/validation-protocol.md)
- 审查新主板模块的候选、目录hash/覆盖、失败比例或开源依据：读取 [当前主板筛选的验证边界](references/validation-protocol.md#当前主板筛选的验证边界) 和 [固定主板目录契约](../ashare-swing-screen/references/screen-contract.md#固定主板目录-get_mainboard_universe)
- 解释回撤、尾部损失、穿透集中度、估值收益分解、风险贡献、仓位模型、求解状态或财商说法中的现金流/回本风险：读取 [风险与数值核对](references/risk-models.md)
- 涉及A股执行、历史规则、费用及资料适用性：读取 [来源与A股验证门槛](references/evidence-and-ashare-gates.md)

按问题读取需要的部分，不机械输出所有清单。用户仅需一般教学时，不索取个人财务资料；实际仓位判断若依赖损失承受、现金需求、持仓或可卖数量，先用已授权信息核实必要输入，缺失就保留未知，不代填风险百分比、资金量或止损数值。

需要研究公司的经营机制、财报质量或估值情景时，使用 [基本面与估值研究](../ashare-fundamental-research/SKILL.md)；本技能仍负责其证据、试验及风险审查，不把估值研究等同已验证策略。

## 决定性门槛

1. 先说明研究对象、证券范围、时间、信号与最早可成交时点、持有/失效规则、基准、成本及风险限制。比较新参数属于新试验，保留失败版本和选择过程
2. 检查当时可得数据、历史成员、退市和状态、复权/公司行动、交易规则生效日期与执行证据。关键缺口不能由现在目录、赢家名单、当前前复权曲线或漂亮图形补齐
3. 先确认时序、持仓现金记账、可卖数量和未成交处理正确，再评价净收益与风险。止损被触发不等于按止损价卖出；无法退出时继续记录真实持仓及后续损失
4. 参数、标准化、特征、风险模型和图结构的拟合仅用当时可得信息；被看着调过参数的测试区间不再称未触碰样本外。检验复杂方法时使用同一范围、成本和执行假设下的简单基准
5. 优先审查最大回撤与水下时间、尾部损失、相关和集中暴露、换手成本及无法退出情景。历史损失、模型VaR/ES、风险预算与止损线都不是未来损失上限
6. 数值问题不可行、缺数据或模型不稳定时，报告具体失败或未知，不静默放松约束、替换数据、删除真实坏行情或凑出“最优仓位”

现有get_swing_screen来源、公式、阈值、65根门槛、匹配语义及过热提示不变；本公开服务完成资格为verified-postclose-v2，按冻结请求开始时刻严格晚于15:30:03可纳入目标日有效新行，source_finality仍unknown。恰好门槛及之前排除当日，旧盘中缓存不因跨线被升级。研究方法不能变成该工具不存在的历史截止日、回测、评分、收益目标或权重参数。过热提示不取消匹配，其阈值不是最大亏损比例。

当前主板模块只取得有界现时目录并对冻结名单用既有固定规则逐批研究；目录hash不包含筛选截止日，也不补齐点时历史成员、真实成交、交易所完整覆盖或收益证据。来源覆盖与筛选账本的两个等式、unknown状态、失败与pending必须分别复核。页面内开始/暂停/继续/失败重试不是后台任务或监控。Qlib/AKShare/vn.py只提供设计参考，未引入其引擎或代码；MIT许可与离线测试不证明固定规则盈利。公共目录调用成功仅验证当次目录，未扫描日线就不称已运行筛选；保留实际公共 source/hash/日期/cache，不套用其他历史来源池或固定总数。旧目录/账号竞价能力已移除；私人策略只在核实能力和授权的本地环境执行。

## 给出与证据相称的结果

先回答“目前能成立什么、关键缺口是什么”。再按需要给出证据范围、最影响结果的失败条件、实际已运行的检查与尚待验证的下一步。可以说“仅理论解释”“数据不足”“合成实现验算通过”“历史测试未通过/仍不确定”“达到事先约定的有限研究门槛”；未实际运行就不能说通过，有限门槛通过也不等于实盘安全。

不为读书或验证自行恢复暂停的云端、访问凭据、改变数据服务或固定筛选接口；不执行交易、开户、转账、自动跟踪或新的长期授权。研究方案、纸面验证和真实交易是不同任务，分别遵守实际授权。
