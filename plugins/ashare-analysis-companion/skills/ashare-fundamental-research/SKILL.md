## 公开源码分发能力边界

此技能源码变体为 1.9.29-public.2，配套 1.27.0-public.2 / public-no-credentials-v2。它与运行中的私有服务及正式安装的 1.9.29 技能能力不同。公开云端的 14 个 MCP 名字中，get_stock_directory、get_auction_snapshot、get_auction_series、get_archive 是四个 unsupported 兼容占位；返回 PUBLIC_PROFILE_LOCAL_REQUIRED 和 local_required=true，不读取环境、数据库、凭据或来源，也不写入数据库。get_diagnostics 仅返回被动元数据与当前实例请求观察，不作上游探测。公开代码不含凭据设置、Access 桥或采集器执行流程；不能通过配置密钥启用被移除功能。

云端筛选只接受公开显式代码和固定 swing-daily-v1；私人名单、阈值、条件及结果只在授权本地执行。无密钥 OHLCV 内核已经准备，但真实 loader、连续更新与盘后调度尚未接入。条件模块 0.1.4（开发候选） 只有 10 条虚构池记录及合成行情，不是实际行业龙头池。详见 [公开技能能力声明](../../PUBLIC-PROFILE.md)。

# A股基本面与估值研究

回答企业怎样赚钱、盈利能否转成股东现金、现价要求什么经营结果，以及哪些事实会推翻判断。依据资料做研究，不把经典观点、财报增长或估值折扣当收益保证。允许暂不估值、没有候选和等待。

## 当前版本与未完成范围

本公开源码的当前能力以实际 schema、description 和返回为准；保留工具名字不等于保留原私有服务的全部参数或功能。get_stock_directory、get_auction_snapshot、get_auction_series、get_archive 四个云端兼容名字均 unsupported，云端只支持公开显式代码的固定规则筛选；被动诊断不能恢复旧能力。先读 [盘后完成与留存边界](../ashare-analysis/references/data-coverage.md#盘后完成与留存边界)。

公开 Worker 已物理移除行情数据库读写、云端持久回退和本地留存 opt-in；不读取既有 D1 快照或归档，get_archive 在云端返回 unsupported。默认 db/schema.ts 为空导出，云端 SQL 不建表、不迁移、不删表；云构建没有 SQL writer、行情 schema 或 portable 存储依赖。官方公共目录只保留有界 isolate 内存缓存。

手工观察、归档、快照回退与私人自选存储只存在于仓库的 portable/local-market.mjs、portable/local-watchlist.mjs、portable/local-observation-store.mjs，须由 portable/sqlite.mjs 的 Node DatabaseSync 工厂签发不可变、仍打开的本地能力。通用 D1、任意 env、客户端 JSON 标记和已关闭实例均被拒绝。显式 127.0.0.1 Node 宿主支持获授权的手工查询与本地留存；此次源码交付未启动实际本地服务。许可存疑行情只在获授权本地保存，不进 Git 或云端长期归档；源码不带真实档案。私人密钥、名单、条件和结果不提交云工具。独立的 OHLCV 更新内核仍未接真实 loader、更新路由或连续/盘后调度；0.1.4 开发条件页面只提供 10 条虚构池记录的合成演示。离线构建和测试不证明目录可访问、真实更新完成或策略盈利。

## 先确认问题与输入

确认证券身份、用户指定范围、研究截止日及问题深度。术语教学或一个指标问题可简短回答，不强制整套研究。实际比较只覆盖已取得资料的公司；当前项目选股范围为沪深普通主板并排除ST名称，明确指定的其他证券研究不得静默加入该筛选池。名称、代码、市场冲突时先核对，不选搜索首条充数。

现有行情工具可提供其实际支持的报价/历史价格，不能从工具名称推断有财务、行业或估值接口。用真实可用工具读取发行人、交易所、巨潮等正式披露，或用户提供的财报；没有权限或正文就说明缺口。网页摘要、书中案例、当前股票目录不能补成完整财报或历史成员表。不虚构财务数据、财务API或批量覆盖，不为研究恢复暂停云端、读密钥或改自选。

## 可复核的研究顺序

1. 建证据包。逐个数值保留报告、页/表、财务期间、披露时间、合并主体、币种单位和版本。先理解行业及收入/成本机制，再选择指标。缺关键输入时只做有证据的部分
2. 对齐三表和附注。区分利润、经营现金、资本支出、融资与股东分配；核查一次性、周期性、并购和稀释影响。高ROE、高增长、负经营现金均需解释来源，不能单凭一个数下结论
3. 写经营假设。把少数决定性变量变成可核查的数量/价格、利润率、再投入与现金路径；分别列支持事实、反证、未知项及复核时点。熟悉产品或自信不代替证据
4. 选择适用估值。使用可解释的经营情景、区间和敏感性；先保证股权/企业价值、现金流/折现率、股本及时间口径一致，再计算。不能从希望的股价倒推一套总能成立的参数
5. 反向检查现价。说明现价要求的盈利、份额、资本回报或持续年限，以及证据能否支持。三种情景不是自动各有三分之一概率；没有概率证据不伪造期望收益
6. 留研究结论和失效条件。使用“资料不足”“经营假设待核”“价格要求偏乐观”“可列进一步核查候选”等有条件表述，给关键依据和下一项核查。不能把估值区间说成未来股价范围或亏损底线

## 与趋势和交易的边界

基本面证据与价格趋势回答不同问题。一次量价命中不等于优质或低估；低估也不确定波段启动时间。需要二者联合时，事前规定研究版本、数据时点、组合条件和退出政策，再验证；不能在技术条件失效后临时改称长期价值持有来回避原规则。

不自动排序成“最值得买”，不生成未经验证的综合分或默认收益目标。若用户要求全沪深主板基本面筛选，先核财务数据覆盖、字段与执行能力；不足时说明未完成范围，可完成有数据的明确子集，但不能拿少量例子冒充全量结果。本技能没有新增指数基金、财务批量接口、回测引擎、交易或自动监控能力。

实际仓位与资金安排才需要核必要的个人约束；一般公司研究不索取个人资产信息。投入模型的假设、模型算术通过、历史样本内表现、样本外证据和真实成交分别报告。
