# Public source skill variant

This is1.9.29-public.2 source for the original ashare-analysis-companion package, paired with1.27.0-public.2/public-no-credentials-v2. It is not a new installed plugin or a formal release update to the user's existing1.9.29 plugin.

Always inspect actual tool metadata. The public source cannot configure, save, read or test provider/Access keys, use a Cloudflare bridge, start collectors or return proprietary account auction histories. The cloud get_stock_directory/get_auction_snapshot/get_auction_series/get_archive names are four unsupported compatibility stubs returning PUBLIC_PROFILE_LOCAL_REQUIRED/local_required=true without environment/database/key/source reads or writes. Do not suggest cloud key entry to make them work. Diagnostics is passive. Cloud screening uses explicit codes and the fixed preset; private lists/thresholds/combinations require local execution.

Cloud market-database readers/writers, local-retention opt-in and durable fallback are physically removed; existing D1 records are not read. The official public directory retains only its bounded isolate-memory cache. The cloud build has no SQL writer, market schema or portable-storage dependency, and its default schema/SQL create, migrate and drop no tables.

Manual observation/archive/fallback/watchlist operations exist only in the repository portable/local-market.mjs, portable/local-watchlist.mjs and portable/local-observation-store.mjs. They require the immutable, open capability issued by the Node DatabaseSync factory in portable/sqlite.mjs; generic D1, arbitrary environment objects, JSON flags and closed instances are rejected. The cloud Worker/bundle cannot import these local modules. The explicit 127.0.0.1 Node host supports authorized manual queries/local retention, but no actual host was started. The separate local credential-free OHLCV engine is preserved but not wired to a real loader, updater route or continuous/postclose schedule. The condition page is synthetic-only. A successful source build or demo does not prove a real leader pool, market update, current source accessibility or investment result. The repository document docs/public-distribution-profile.md describes the exact source/deployment differences; that repository document is not part of a separately extracted skill package.

The bundled documents describe the reduced current capabilities. Removed credential/bridge/collector execution instructions are not preserved as a historical recovery flow. Existing formal source hashes and current variant hashes are distinct; this variant is not claimed to match all14 formally released texts byte for byte.
