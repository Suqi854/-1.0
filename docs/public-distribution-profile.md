# Reduced public source profile

This source is 1.27.0-public.2 / `public-no-credentials-v2` of the same project. The running owner-private Site remains 1.27.0 and the installed formal skills remain 1.9.29. No private deployment, database, stored key or separate Cloudflare production service was changed by this source-only reduction. This is not a byte-identical or full-capability mirror of that deployed version.

The public source physically excludes the Access/Cloudflare bridge target and authenticated transport, credential settings and provider-key readers, HiThink source calls, account auction samples/health, collector coordination and scheduled/start-stop code. Their legacy offline execution material is also excluded rather than moved into another directory. Credential/collector schema creation is absent. Existing private runtime data is not cleared or migrated by this work.

Credential-free manual quote/bar/intraday/MACD, Eastmoney delayed premarket observations, public context and official-directory readers remain. The 14 legacy MCP names remain discoverable in the cloud, but `get_stock_directory`, `get_auction_snapshot`, `get_auction_series` and `get_archive` are four unsupported compatibility stubs. They return `available=false`, `data_status=unsupported`, `code=PUBLIC_PROFILE_LOCAL_REQUIRED` and `local_required=true` without environment/database/key/source reads or writes; this is not an empty successful response. `get_diagnostics` is passive and does not probe sources or credentials. Its public schema revision is `2026-10-03.public.2` and its fingerprint differs from the private version. The cloud swing interface exposes explicit codes and the fixed public preset only; private `original_watchlist` and custom thresholds are rejected in cloud mode and belong only to a separately authorized trusted local host.

The public Worker rejects credential/bridge/private-watchlist routes with HTTP 501 before reading a request body. The page contains no key/Access credential form or collection control. Conditions stay in browser memory/local downloads, with the unchanged synthetic-only client editor and network-blocking CSP. No real industry-leader pool, personal preference or private rule is included.

All cloud market-database readers/writers and local-retention opt-in exports are physically removed. The former `src/history-archive.mjs`, `src/snapshot-store.mjs`, `src/auction-store.mjs` and `src/watchlist.mjs` are absent from the cloud source. Cloud queries neither read existing D1 records nor fall back to durable snapshots or archives. Only transient credential-free source reads, request-local observations and the official public directory's bounded isolate-memory cache remain. The cloud build has no SQL writer, market schema or portable-storage dependency.

Manual observation retention, archive reads, snapshot fallback and private watchlists are implemented only in `portable/local-market.mjs`, `portable/local-watchlist.mjs` and `portable/local-observation-store.mjs`. Every storage operation requires the immutable capability issued by the Node `DatabaseSync` factory in `portable/sqlite.mjs`. Generic D1 bindings, arbitrary environment objects, client JSON flags and closed instances are rejected. The cloud Worker and bundle cannot import these local modules. The explicit Node host binds to `127.0.0.1` and supports authorized manual queries/local retention; this source delivery did not start an actual host.

The earlier collector path depended on a provider credential and has been removed together with its execution instructions. This source provides no collector-enabling switch or recovery flow. The credential-free local OHLCV updater/store remains prepared with its four sequences, leases, bounded advance, pause/checkpoints and synthetic tests. Real local source loading and continuous/postclose scheduling are still not integrated or enabled. Manual queries are not presented as satisfying daily update requirements.

The default `db/schema.ts` contains only an empty export. The default cloud SQL in `drizzle/0000_public_manual_observations.sql` is a no-op: it creates, migrates and drops no tables. Local manual-observation/watchlist DDL exists only in `portable/manual-observations.sql` and is opened explicitly through the trusted Node factory. No cloud operation reads, clears or migrates existing databases, and no credential or collector schema is provided.

The bundled skill source variant is1.9.29-public.2 under the original package name. Its skill text and reference documents describe unsupported capabilities directly. The installed formal1.9.29 plugin was not republished or changed. Original formal hashes and current variant hashes are recorded separately, and private deployment/document references remain generalized. No new plugin or software license was selected.

The 54 removed credential/bridge/collector runtime and test paths remain excluded, with their exact paths in the machine export manifest. This profile's test total must be measured against the final current tree; previous private-release and public-variant totals are not current coverage. Verification uses only synthetic inputs and temporary synthetic local stores, with no real source request, runtime database, key lookup, collector activation, actual local-host start or private deployment.
