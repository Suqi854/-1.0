# Public profile cloud boundary

This 1.27.0-public.2 / `public-no-credentials-v2` distribution has no Cloudflare bridge, key/Access configuration or collector control. The 54 removed credential/bridge/collector runtime and test paths remain excluded. The running private Site 1.27.0, installed formal skills 1.9.29 and old independent Cloudflare production are outside this source-only change. See the [public distribution profile](public-distribution-profile.md).

The cloud Worker performs transient credential-free public queries without market-database reads, writes or durable fallback. `get_archive` joins `get_stock_directory`, `get_auction_snapshot` and `get_auction_series` as an unsupported `PUBLIC_PROFILE_LOCAL_REQUIRED` compatibility stub. Existing D1 records are not consulted. The official public directory retains only its documented isolate-memory cache. Cloud storage helpers and local-retention opt-in exports are removed, and the cloud bundle has no SQL writer, schema or portable-storage dependency. `db/schema.ts` is an empty export; the default cloud SQL creates, migrates and drops no tables.

Manual observation/archive/fallback and private-watchlist logic exists only under `portable/` and requires an open immutable capability issued by the Node `DatabaseSync` factory in `portable/sqlite.mjs`. D1, arbitrary environment objects, JSON flags and closed instances cannot grant it. The explicit `127.0.0.1` Node host supports authorized manual queries and local retention; no actual host was started. Private lists/conditions and any permitted long-term observations stay local. The separate no-key OHLCV updater/store remains prepared without a real loader, continuous/postclose schedule or enabled start operation. No collector execution path or cloud timer is provided.
